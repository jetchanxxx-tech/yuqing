# 盘古舆情 · Demo 演示文件包

## 使用方法

**双击 `index.html` 即可在浏览器中打开演示**。无需服务器、无需安装任何依赖、离线可用。

## 演示流程（全程仅需 2 次点击）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 开场屏 | 点击【开始演示】 |
| 2 | 新建分析 | 关键词已预填「雅阁后排」，点击【开始分析】 |
| 3 | 分析进度 | 状态机 6 状态自动流转 + 采集日志滚动（约 40 秒自动完成） |
| 4 | 结果总览 | 声量趋势 / 情感分布 / 平台来源 / 话题聚类 / 热门内容 |
| 5 | 多 Agent 辩论 | 4 位专家 Agent × 3 轮辩论（打字机效果自动播放）+ 主持人研判 |
| 6 | 报告预览 | 《「雅阁后排」舆情研判报告》完整版 |
| 7 | 用量套餐 | Token 扣减动画 + 4 档套餐对比 |

## 演示要点

- **核心卖点**：步骤 5 的多 Agent 辩论是产品差异化所在，演示时建议完整播放
- **状态机**：步骤 3 展示 6 个状态流转（排队→预算→采集→分析→报告→完成）
- **数据真实感**：步骤 4 的所有图表数据均围绕"雅阁后排"事件定制

## 现场演示建议

1. 开场介绍一句话："这是一款把舆情监测升级为舆情研判的 AI 产品"
2. 点击【开始演示】→ 展示关键词预填 → 点击【开始分析】
3. 进度播放时介绍："状态机自动流转，真实采集微博/新闻/小红书/B站 4 平台"
4. 结果页停留 30 秒，重点讲情感分布和话题聚类
5. **辩论回放是高潮**，让打字机效果完整播放
6. 报告页讲"自动生成，可溯源"
7. 套餐页讲定价，引导注册
