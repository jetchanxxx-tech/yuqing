# PRD 概要：AI 原生 SaaS 舆情监测平台（MVP）

**状态**: Approved v1.0 | **日期**: 2026-08-11
**定位**: 面向中小企业与个人品牌的 AI 原生舆情监测平台——用多 Agent 辩论协作把"监测"升级为"研判"，把传统工具每年数万元的门槛降到每月几十元。

## 2. MVP 功能清单（P0 — 10 项）

| # | 功能 | 说明 |
|---|------|------|
| F01 | 账号体系与多租户 | 注册/登录(JWT)、组织创建、Database-per-tenant |
| F02 | 监测任务管理 | 创建/编辑/暂停；关键词+排除词+平台+频次 |
| F03 | 数据采集管线 | 5 数据源（微博/公众号/新闻/小红书/B站），去重入库 |
| F04 | 实时数据看板 | 声量趋势、情感分布、平台分布、Top 内容、热词 |
| F05 | 单 Agent LLM 摘要 | 每日自动摘要（基础版，非辩论） |
| F06 | 报告生成 | 日报/周报模板，HTML/MD 导出 |
| F07 | 计费与用量计量 | 套餐定义、次数/token 实时扣减、超额拦截 |
| F08 | 数据保留策略 | 30/90天自动清理 |
| F09 | 管理后台 | 用户、套餐、用量、订单 |
| F10 | 邮件告警 | 阈值告警（声量突增/负面激增） |

**MVP 明确不做**：
- 多 Agent 辩论（P1 第 2 周上线，token 消耗大需先验证付费）
- 多模态/短视频理解（P1）
- 政务私有化部署（P2）
- PDF 导出（P1，HTML/MD 先覆盖）

---

## 3. 核心差异化

1. **多 Agent 辩论研判**（P1 上线，唯一性最强核心卖点）— ForumEngine 主持人协调多专家 Agent 辩论，结果更可靠可解释
2. **价格带宽碾压** — 传统工具 ¥3-8 万/年 → 我们 ¥0-499/月
3. **AI 原生 + 多模型不绑定** — DeepSeek/Kimi/Qwen 可切换
4. **多模态覆盖** — 短视频/图片理解直击抖音/小红书盲区
5. **开放 API + 开发者生态** — 开源基因，嵌入客户系统
