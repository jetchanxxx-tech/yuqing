使用说明

  • PPT 的文字与图形可编辑。字体使用 Noto Sans CJK SC；Windows 未安装时，可在 PowerPoint 中替换为微软雅黑（Microsoft YaHei）。
  • HTML 预览无需外部依赖，可离线打开；支持方向键、上一页／下一页、Home／End 和触控翻页。PDF 用于固定版式审阅。
  • 客户版控制在 6 页。渠道合作、里程碑与商业指标中的拟议事项均有标注；虚构示例不作为真实客户案例。
  • 当前介绍以单次公开网页摘要分析、三维／五维研判和 HTML 报告为主。商业目录为报告额度包；真实通知与商户支付需要另行联调。
