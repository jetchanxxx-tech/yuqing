确定的行为

  • 报告完成前取到本轮 HTML 并随完成流程传递；PostgreSQL 在插入报告时加分析行锁捕获对应版本。查看、重跑或再次下载不能修改已发布版本；不再从可变的分析行读取旧报告。
  • Word 导出缺失内部认证配置时拒绝服务，密钥不匹配时拒绝请求；转换在 FastAPI 线程池执行，保持引擎事件循环可用。Word 直接转换已保存 HTML，保持摘要、维度、风险、原文引语及来源明细，不重新检索或调用 LLM，不产生新的模型用量。
  • 界面只提供已实现的 HTML 与 Word 下载。Word 仍遵循所请求格式的套餐权限，跨租户及未核验 API Key 所有者边界保持。
  • 0030 为 reports 增加 content_html，插入时在分析行共享锁下捕获，数据库触发器防止修改。报告列表只返回是否有版本正文，不返回大段 HTML。
  • 历史回填只处理当前完成分析的最新 HTML 报告，要求记录创建于该次完成之后且完成时间可核验。无法核验的旧版保留记录、明确正文不可用，不把新内容冒充历史版本。
  • 快照随原报告记录按现有保留政策清理；金融流水、用户资产和模型费用事实不变。迁移禁止破坏式 down。
