K2 账号、角色与租户接口契约

冻结日期：2026-10-09。状态：契约与失败验收用例准备；未声称已实现、通过验收或部署。依据 管理后台开发计划 K2。全部路径以前缀 /api/v1 开始；不包含邀请、新成员创建和登录设备管理。

读取与分页

列表使用 page=1&page_size=20，page ≥ 1，page_size 1–100；非法数字或超限返回 400。按 created_at ASC,id ASC 排序，同创建时间下分页稳定。响应 {items:[],total,page,page_size}；租户列表额外保留 tenants，内容与 items 相同。时间均为 RFC3339；未发生的时间为 null，空集合为 []。

路径查询／权限响应
GET /admin/usersq（邮箱／昵称／ID）、status、platform_role=platform_admin、verified=email|phone|none；admin:users:read用户分页
GET /admin/users/:idadmin:users:read用户详情
GET /admin/tenantsq（名称／ID）、status、plan_code（有效套餐）；admin:tenants:read（旧 admin:tenants:list 保留）租户分页＋兼容 tenants
GET /admin/tenants/:idadmin:tenants:read租户详情
用户行：{id,name,email,phone_masked,status,email_verified,phone_verified,
  platform_roles:[],tenant_count,created_at,last_login_at:null,row_version}
用户详情：用户行 + {memberships:[{tenant_id,tenant_name,tenant_status,role,row_version}],
  audit_logs:[]}
租户行：{id,name,slug,plan_code,status,created_at,row_version,user_count,
  effective_plan_code,plan_source}
租户详情：租户行 + {members:[{user_id,name,email,role,row_version}],
  credit:null|{balance,plan_code},orders:[],audit_logs:[]}
审计摘要：{id,actor_id,action,target_type,target_id,tenant_id,reason,
  before,after,request_id,created_at}

手机号仅返回脱敏 phone_masked（中国 11 位示例 138****0011），无绑定返回空字符串。不能返回密码散列、JWT、验证码或原始手机号。平台角色与团队成员角色分别返回。tenant_count／user_count 为实际成员关系计数，不能假定一用户一租户。有效套餐采用 report_credits.plan_code（plan_source=report_credits），与报告权限来源一致；无额度池时 effective_plan_code 为空字符串、plan_source=unknown，继续适用报告模块的最严格限制。tenants.plan_code 只显示历史字段，不据此补造有效权益。订单只读既有 orders，无购买记录不得造 paid 订单。

状态、角色与并发

路径请求与权限成功响应
POST /admin/users/:id/disable
POST /admin/users/:id/enable		{reason,expected_version}；admin:users:manage{id,status,row_version}
PUT /admin/users/:id/platform-role{platform_admin:boolean,reason,expected_version}；admin:roles:manage{id,platform_roles:[],row_version}
POST /admin/tenants/:id/suspend
POST /admin/tenants/:id/resume		{reason,expected_version}；admin:tenants:manage（旧 admin:tenants:suspend 保留）{id,status,row_version}
PUT /admin/tenants/:tenant_id/members/:user_id/role{role,reason,expected_version}；admin:members:manage{tenant_id,user_id,role,row_version}

上述管理权限仅授予持久化的 platform_admin；tenant_admin／analyst／viewer 和 API Key 均不可访问。reason 去除空白后必填；expected_version 必填且 ≥ 0。账号及平台角色使用 users.row_version，租户使用 tenants.row_version，成员使用 tenant_members.row_version。版本不一致返回 409且不修改数据／审计。

账号仅 active→disabled、disabled→active；启用不能重新激活 pending_activation、closure_pending 或 closed。平台管理员角色只按不可变 user_id 授撤；成员角色白名单 tenant_admin／analyst／viewer，禁止 platform_admin／api_service。按显式 tenant_id＋user_id 定位已存在成员，缺失 404，不创建任何成员。

账号状态／平台角色操作持有与 K1 共用的 auth.PlatformAdminLockID=741914 事务锁，成功后必须至少保留一名 active 平台管理员；两个管理员并发互撤／互禁只能一个成功。成员操作持有对应租户事务锁，至少保留一名 tenant_admin；并发降级两名管理员只能一个成功。CAS、状态／角色、版本和持久审计同事务提交，审计失败则全部回滚。

账号状态／平台角色成功变更递增目标 users.row_version 与 token_version。成员变更递增成员 row_version、目标 users.row_version 与 token_version；同账号其他团队关系保持。旧 access／refresh 在下一请求返回 401；启用／重新授权不恢复旧凭据。租户挂起／恢复递增租户 row_version，不能修改用户状态或清除成员；新业务请求读取当前租户状态。

持久审计与错误

复用 audit_logs：actor_id、tenant_id、action、resource 和 details_json，JSON 内保存 target_type／target_id／reason／before／after／request_id。时间取真实数据库时间。读取在服务重新装配后仍保留；不使用请求 logger 代替审计。动作名采用 user.disable、user.enable、user.platform_role、tenant.suspend、tenant.resume、member.role。

错误信封 {code,message,request_id}。400 BAD_REQUEST：输入／角色不合法；401 UNAUTHORIZED：身份或凭据撤销；403 FORBIDDEN：平台权限不足；404 NOT_FOUND：目标／成员不存在；409 CONFLICT：版本、状态跃迁或最后管理员冲突。错误不返回 SQL 或秘密。

验收边界

真实 router memory HTTP 用例验证 DTO、权限、白名单和撤旧 token；GitHub hosted PostgreSQL 用例验证并发最后管理员、CAS、成员范围、审计事务回滚、重新装配持久、多人计数、同时间分页与套餐来源。使用 pgtest 独占 schema；不发送邮件／短信，不运行生产支付，编译与执行仅由批准的 GitHub 工作流完成。云端失败、成功 run 的准确 commit 及结果由主执行者记录到交付状态页。

冻结契约可供 K3 前端实现；实施状态以 GitHub 验收证据和交付状态页为准。
