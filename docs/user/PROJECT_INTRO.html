市场机会与痛点

传统舆情工具的四道门，把中小企业挡在门外

舆情监测不是新市场，是传统玩家把市场做小了：年费数万、合同以月计、部署以季度计——服务对象基本只有大企业和政府。真正每天站在舆论一线、却没有任何工具可用的，是它们。

PAIN 01

价格高

年费 ¥3–8 万 + 实施费 + 按席位加价；销售谈判周期以月计，续费还要再谈一轮。

我们的打法：¥0 / ¥99 / ¥499 三档自助订阅，信用卡即开即用，随时可取消。
PAIN 02

洞察浅

系统只给词频、图表、报警——「报数不报因」。深度结论靠分析师人肉写，一份报告 1–2 天。

我们的打法：多 Agent 辩论研判：直接输出结论 + 证据 + 分时段的处置建议。
PAIN 03

形态落后

以文本监测为主，短视频 / 图片 / 弹幕是盲区——而舆论主战场早就在抖音、小红书、B 站。

我们的打法：AI 原生架构，多模态理解在路线图内；消费级界面体验。
PAIN 04

交付慢

私有化部署动辄数月；模板固定，改个报告格式都要排期等版本。

我们的打法：SaaS 注册即用，向导 4 步建任务，注册后 5 分钟内出报告。
内容爆炸：日增内容以亿计，人工无法覆盖 大模型平价化：国产模型让「理解内容」第一次比「采集内容」便宜 决策要快：舆情从发酵到失控只有 24–48 小时

一句话痛点共鸣（开场用）

「传统舆情工具是给有预算、有时间、有团队的人准备的。而舆情危机从来不等预算、不等时间、不等团队——这就是微舆舆情存在的理由。」

常见问答

十个高频问题与标准回答

原则：先给结论（黑体），再补论据，答完拉回自己节奏（「这个问题的答案，正好说明刚才讲的 XX」）。

Q1为什么你们能卖这么便宜？传统工具凭什么收 3–8 万一年？
因为商业模式不同，不是打价格战。 传统厂商成本大头是销售团队、实施部署、私有化定制，全要摊进年费。我们是纯 SaaS：自助注册无销售成本、注册自动开库无实施成本、AI 按 Token 计量转售用多少付多少。订阅制 + 按量封顶，用户没有「被套牢」风险，所以我们敢把门槛放到 ¥0。
Q2数据从哪里来？合规吗？会不会有法律风险？
采集平台公开内容，保留期到自动删除，租户数据物理隔离。 首批 5 大公开源（微博/公众号/新闻/小红书/B 站），只采公开可见内容；采集策略平台统一管理、用户不可配置——傻瓜化也是合规化。30/90/365 天保留自动清理；每租户独立数据库物理隔离。演示「雅阁后排」数据为定制示例数据，真实产品中以你自己的关键词触发真实采集。
Q3AI 结论准吗？会不会一本正经胡说八道？
两个机制对抗幻觉：证据引用 + 多 Agent 交叉质询。 统计数字来自结构化分析引擎对采集文档的统计，不是 LLM 生成——LLM 只做归纳、辩论与建议；每条结论挂证据，第二轮交叉质询就是专家互相挑错，主持人给置信度评级（案例 0.87）。报告标注 AI 生成并提供复核入口。我们不承诺 100% 准确，但保证每条结论都能说清依据。
Q4和清博、知微、慧科这些传统厂商比，差在哪、好在哪？
定位不同：它们做「监测基建」，我们做「研判外脑」。 坦白说，数据源广度（历史库、政务数据、全网回溯）与定制深度，头部厂商沉淀多年确实更全——那也是它们收 3–8 万的原因。我们解决的是它们覆盖不到的中小品牌「出事了怎么办」：价格（0/99/499 自助）、速度（注册 5 分钟出报告 vs 部署数月）、深度（多 Agent 辩论直接给处置方案 vs 给报表自己分析）。
Q5能私有化部署吗？数据能放我们机房吗？
Enterprise 阶段支持，架构天生为此设计。 部署形态是 Go 二进制 + systemd、无容器依赖；database-per-tenant 物理隔离——私有化时把租户库与进程搬到客户机房即可。政务级私有化（等保、信创适配）在 P2 路线图，随 Enterprise 方案交付。SaaS 阶段数据同样租户隔离 + 到期删除。
Q6数据安全怎么保证？我的竞品信息会被别的租户看到吗？
数据库物理隔离 + 双层权限 + 加密传输，租户间不可能串数据。 注册即建独立数据库；平台库（账号计费）与业务库（分析数据）分层、代码层面约束互不越界；JWT + RBAC 每请求校验租户归属；操作留审计日志。你的关键词、报告只有你的团队席位可见。
Q7用的是什么大模型？会不会被一家模型绑定？
不绑定：DeepSeek / Kimi / Qwen / Moonshot 等主流模型可切换。 统一 OpenAI 兼容接口封装；底层任何一家 API 不稳定时自动 fallback 备选供应商，任务不中断。Enterprise 支持 BYOK（自带 Key 或私有化 vLLM/Ollama）。进价与售价两本账，明码标价，你看到的价格就是结算价。
Q8免费版够用吗？辩论分析为什么免费版没有？
免费版是「完整产品、限量配额」——够个人 IP 起步、够验证价值。 每月 5 次分析、1M Token、1 席位、保留 30 天——刚才整套深度研判约 1.2 万 Token，5 次额度能完整跑 5 次。辩论单次 Token 消耗约为普通分析的 3 倍，故计 3 次分析、只在 Pro 及以上开放——这是 Free 保护成本、Pro 有真实付费理由的设计。
Q9我直接用 ChatGPT / DeepSeek 提问不就行了？
大模型不会替你采集数据，更不会替你开评审会。 问 ChatGPT「雅阁后排怎么样了」，它只能凭训练数据回答且可能早已过时。我们做的事：先采集（四平台实时内容去重入库——数据而非模型记忆）、再分析（情感话题结构化统计）、最后研判（四专家辩论）。外加计量计费、报告导出、每日自动监测工作流。ChatGPT 是问答题，我们是完整的舆情作战流水线。
Q10上手要多长时间？我们团队没人懂舆情分析。
注册到第一份报告，验收标准 5 分钟以内。 新建任务 4 步向导：类型 → 关键词/平台 → 成本预估 → 提交，然后全自动。日常每天 10 分钟：看趋势、读研判、有告警邮件才行动；季度汇报报告中心一键导出。设计原则：不需要你懂舆情分析——分析的部分 AI 做了，你只需要懂你的品牌。
