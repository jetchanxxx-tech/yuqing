微舆舆情 · 用户手册

微舆舆情（Yuging）是一款面向中小企业与个人品牌的 AI 舆情监测平台：自动采集微博、公众号、新闻、小红书、B 站、抖音等平台的公开讨论，用 AI 完成情感研判、话题聚类与报告生成，把传统舆情工具每年数万元的门槛降到每月几十元。

适用版本：技术预览版（MVP · 2026-09） 读者对象：品牌市场人员 / 公关 / 运营 / 管理者 阅读方式：在线浏览，建议先读第 1 章

如系统页面与本文描述不一致，以页面实际显示为准；标记「即将推出」的功能目前尚不可用，属正常情况，详见第 7 章。

1

快速上手（5 分钟）

从零完成：注册 → 创建第一个分析 → 查看分析结果
1 注册账号 约 1 分钟
  1. 在浏览器中打开平台网址（例如 https://your-domain.com），进入登录页。
  2. 点击登录页中「注册微舆舆情」入口，进入注册页。
  3. 填写三项内容，然后点击「注册」：
字段填写要求示例
姓名必填，用于团队内识别王芳
邮箱必填，需为有效邮箱格式，作为登录账号wangfang@example.com
密码必填，至少 8 位建议字母 + 数字组合

注册成功 = 自动开通

系统自动完成三件事，无需任何额外操作：① 创建你的专属工作空间（术语叫「租户」，见术语表）；② 将你设为该空间的租户管理员；③ 开通免费版套餐——每月 100 万 Token 额度 + 5 次分析次数（见2.7 套餐与用量）。随后自动登录并进入「数据面板」。

提示：同一邮箱不能重复注册。如果提示「邮箱已存在」，请直接登录，或联系客服处理。

[截图: 注册页 —— 姓名 / 邮箱 / 密码表单]
2 创建第一个分析 约 2 分钟
  1. 点击左侧菜单「新建分析」，进入 4 步创建向导。
  2. 第 1 步「分析类型」：先给分析起名（至少 2 个字、最多 50 字），再在四种类型卡片中选择一种，例如「品牌声誉监测」，点击「下一步」。
  3. 第 2 步「关键词设置」：输入想监测的关键词后按回车键确认（可添加多个）。页面下方提供「舆情、口碑、投诉、召回、涨价、新品」等常用补充词，点击即可快速添加。至少添加 1 个后点击「下一步」。
  4. 第 3 步「数据源选择」：勾选至少 1 个平台（微博、公众号、新闻、小红书、B 站、抖音均可多选），点击「下一步」。
  5. 第 4 步「确认提交」：核对名称、类型、关键词与数据源，页面会显示成本预估（预计消耗多少 Token、剩余额度多少）。点击「提交分析」。

提交后页面自动跳到该分析的详情页，任务状态显示为「排队中」。

示例：想监测你的品牌口碑？输入「品牌名 + 产品/场景词」，例如「雅阁 后排舒适性」，比单独输入「雅阁」更聚焦。

3 查看分析结果 约 2 分钟
  1. 在详情页顶部查看任务状态标签（「排队中」「预算校验」「数据采集」…）与进度条。页面每 5 秒自动刷新，也可以点「刷新状态」手动刷新；执行中可随时点「取消任务」终止。
  2. 等待状态变为「已完成」（绿色标签）后，右侧显示 4 个结果标签页：文档列表（采集到的内容原文，可跳原始链接）、情感分析（正面 / 中性 / 负面占比）、话题聚类（讨论集中的话题及趋势）、分析报告（AI 生成的洞察报告）。
  3. 在「分析报告」标签页点「下载 HTML」（免费版支持 HTML 格式），即可将报告保存到本地。

预览阶段说明：数据采集与 AI 研判当前使用内置演示内容，用于体验完整流程；真实数据采集与分析即将上线，见第 7 章。若结果标签页显示「未采集到公开文档」或「暂无话题聚类结果」，均属该阶段的正常现象。

2.2 数据面板

「数据面板」是登录后的首页，汇总你名下全部监测任务的数据，适合每天花几分钟掌握舆论态势。整体分 5 个区域：4 张概览卡、3 张图表、1 个话题榜单。右上角显示「更新于」时间与「刷新」按钮（概览卡片约每 60 秒自动刷新一次）。

第 1 步：分析类型

先填写分析名称（必填，至少 2 个字、最多 50 字，例如「新品发布会舆情监测」），再选择类型：

类型适用场景举例你能得到什么
舆情事件分析突发负面事件、热点话题事件传播路径、热度拐点与脉络
品牌声誉监测日常口碑监测、声誉风险排查品牌口碑走势、风险识别与应对效果评估
竞品动态追踪盯住竞争对手动作竞品新品 / 活动 / 口碑的市场反馈信号
行业趋势洞察观察整个行业讨论话题演变、用户关注点迁移

第 2 步：关键词设置

输入关键词后按回车确认，生成一个标签；点标签上的「×」可删除。规则与技巧：

  • 至少 1 个，最多 20 个；建议 2–5 个组合使用；
  • 关键词越具体结果越精准。单一宽泛词（如「汽车」）会混入大量无关内容；
  • 推荐「品牌词 + 产品词 / 场景词」组合：如「雅阁 后排舒适性」比单独「雅阁」更聚焦；
  • 系统提供「舆情、口碑、投诉、召回、涨价、新品」常用补充词，点击即加；
  • 想扩大覆盖面，可加入产品别名、拼音缩写等变体。

第 3 步：数据源选择

数据源内容特点
微博实时热点与事件发酵主阵地，舆情爆发最先出现的地方
公众号深度长文与行业观点
新闻媒体报道与转载，权威性高
小红书消费口碑与种草讨论，适合消费品牌
B 站年轻用户深度讨论、测评向内容
抖音短视频评论（数据采集能力即将推出，见第 7 章）

首次体验建议勾选 2–3 个与你最相关的平台，覆盖面与速度更均衡。

第 4 步：确认提交（成本预估）

页面显示本次配置与成本预估：
预计消耗约 X tokens（关键词 2 × 数据源 3 × 1200，另含报告生成约 3000）／ 当前剩余额度 Y tokens

估算规则：每个「关键词 × 数据源」组合约消耗 1,200 Token（采集摘要 + 研判），另加报告生成固定约 3,000 Token。若剩余额度可能不足，页面会以橙色提示建议「减少关键词 / 数据源」或「升级套餐」。

排除词（屏蔽无关内容）、监测时间范围等高级参数将在后续版本提供，见第 7 章。

2.4 分析状态机：9 种状态详解

一次分析从提交到出结果会依次经过多个环节，系统用「状态」告诉你任务当前进行到哪一步。正向流程为「草稿 → 排队中 → 预算校验 → 数据采集 → 智能研判 → 报告生成 → 已完成」；执行中任一环节都可能失败或被你取消。

已完成 / 成功 已取消 / 预警 失败 执行中环节 草稿（内部状态）

图：分析任务状态流转总览（详情页时间线即该图的动态版，运行中的当前环节显示红色脉冲动效）

9 种状态与「你能做什么」

状态（代码）页面标签含义此时你能做什么
draft草稿任务已创建尚未排队（内部状态，向导提交后不会停留在此）一般不会看到
queued排队中已进入执行队列等待调度。同时运行的任务数达到套餐上限（免费版 1 个 / 专业版 2 个 / 企业版 5 个）时，新任务会在此等待空位可取消；等待页面自动刷新
acquiring_budget预算校验正在校验本次分析的 Token 额度是否充足可取消
fetching数据采集正在从各平台采集公开内容可取消（将终止本次采集）

要点

取消仅对执行中任务开放，取消后不生成报告、已消耗额度不退回（见FAQ Q6）；「重新运行」仅对终态任务开放，按原参数重新排队，会再次消耗 Token。

任务列表与详情页在有任务运行时每 5 秒自动刷新，进入终态后停止自动刷新。

2.5 分析详情页

从「分析任务」列表点击任务名称（或创建后自动跳转）进入详情页，页面分为三块：

  • 顶部概览卡：任务名称、状态标签、任务 ID、创建时间、进度百分比与进度条；运行中显示「刷新状态」；执行中可「取消任务」，终态可「重新运行」；失败时用红框显示失败原因。
  • 左侧「任务进度」时间线：把执行环节画成时间线——已完成环节绿色、当前环节红色旋转动效、未开始环节灰色；失败 / 取消时对应终止点显示原因（如「失败：预算不足」）。
  • 右侧内容区随状态变化：运行中显示环节提示语（如「正在从各平台采集公开数据」）；已完成显示 4 个结果标签页；失败 / 已取消显示结果说明与操作按钮。

文档列表

本次分析采集到的内容条目：标题（点击打开原始链接）、来源平台标签、来源账号与发布时间、正文摘要（可展开 / 收起）。这里是核对 AI 结论、追溯原始出处的地方。

情感分析

三张统计卡 + 环形图：正面 / 中性 / 负面占比（%），色卡与数据面板一致（绿 / 灰 / 红）。回答「大家讨论的口气是夸还是骂」。

话题聚类

表格列出本次讨论聚成的若干话题：话题名、相关文档数（带条形对比）、趋势（上升 / 下降 / 平稳）。回答「大家在聊哪几件事、哪件在发酵」。

分析报告

AI 生成的洞察报告，分析完成后自动生成，按套餐支持多种格式下载（见2.6），也可点「前往报告中心」统一管理。

Token 是什么，怎么消耗

Token 是大模型（AI）理解文字的最小计量单位，约等于 1 个汉字或 1 个英文单词的一部分，代表你的「AI 算力配额」。每次分析中，AI 会在三个环节消耗 Token：采集内容的摘要理解、智能研判（情感 / 话题分析）、报告生成。创建分析向导第 4 步会给出本次预估消耗。

告警配置教程

阈值规则创建 · 触发条件解释 · 收件人配置

3.1 告警是什么

告警是系统的「哨兵」：当某次分析发现负面情绪占比达到你设定的阈值时，系统会触发告警并发送提醒邮件，让你不必时时盯看面板，也能在负面舆情超标的第一时间知道。

当前版本状态

阈值规则的创建、存储与触发检查已在系统中实现并通过测试；邮件发送通道尚未接通（触发已生效、发信待配置），Web 端自助配置入口即将推出。以下说明规则包含哪些配置、如何取值；预览期间如需配置规则，可通过客服渠道提交给平台管理员代为配置（字段与本文一致）。

1 创建一条阈值规则 自助入口即将推出

进入告警规则管理页（后续版本从「数据面板」进入）后：

  1. 点击「新建告警规则」；
  2. 填写规则名称：用于在列表中区分，建议写明用途，例如「品牌危机红线」；
  3. 设置触发阈值：即负面情绪占比的警戒线。系统内部按 0–1 的小数记录（0.3 = 30%），配置时按百分比填写即可；
  4. 填写通知邮箱：触发后接收提醒邮件的邮箱，建议使用团队值班邮箱而非个人邮箱；
  5. 点击「保存」。规则创建后立即生效，用于后续的分析结果检查。
[截图: 新建告警规则表单 —— 名称 / 阈值 / 通知邮箱]

阈值怎么选

阈值决定告警的「敏感度」，可参考下表起步，再按品牌实际情况调整：

场景建议阈值说明
高敏感品牌 / 高危期30%（0.3）负面稍有抬头即提醒，宁多收信不漏报
常规监控50%（0.5）负面过半才提醒，兼顾噪声与灵敏度
危机红线70%（0.7）只在大规模负面爆发时触发，用于危机确认

经验法则：阈值越低越早收到提醒，但个别差评也会频繁打扰；阈值过高则可能漏掉从 40% 一路爬升的负面趋势。建议先用 50% 跑一段时间，再按实际收信频次调整。

2 理解触发条件

规则触发遵循以下逻辑，理解它有助于避免误判：

  • 每次分析产生情绪结果后，系统计算负面内容占比；
  • 若占比大于等于阈值，规则触发：记录触发时间，并向通知邮箱发送提醒邮件（内容含规则名称与当前负面占比）；
  • 一条规则只判断自己：阈值 70% 的规则不会因负面占比 30% 触发，即使另一条阈值 30% 的规则已经触发；
  • 多条规则可同时触发：负面占比 85% 时，30% / 50% / 70% 三条规则各自独立触发；
  • 只要触发条件成立就会再次提醒（当前无冷却间隔）：连续多次超标会连续收信，直到占比回落。若正处危机期且邮件过密，可临时提高阈值或联系客服调整。
3 收件人配置与验证
  • 每条规则当前支持一个通知邮箱；一个团队可配置多条规则、各配不同收件人（如「公关值班邮箱」「老板邮箱」各一条）；
  • 建议先填自己的邮箱做一次测试（临时调低阈值触发一次），确认收信正常后再调整为正式阈值；
  • 触发邮件可能被误判为垃圾邮件，首次使用请将平台发件地址加入通讯录。

常见问题 FAQ

点击问题展开答案（共 16 条）
Q1Token 用完了怎么办？

看你的套餐属于哪种预算模式：

  • 免费版 / 专业版（硬上限）：额度用尽后新分析无法开始，系统提示预算或配额不足。解决方式：升级到更高套餐获得更大额度，或等待下个计费月额度重置（按自然月刷新）。
  • 企业版（超额计费）：超出部分按套餐费率计入账单，分析不会中断。
  • 旗舰版：无上限，按约定结算。

此外，创建分析时关键词 × 数据源越多消耗越大，额度紧张时可适当精简。用量页仪表盘变橙色（已用超 80%）就是预警信号。

Q2为什么下载不了 PDF / Word 报告？

报告格式按套餐开放：免费版仅 HTML，专业版为 HTML + Markdown，PDF 与 Word 需企业版及以上。如你的套餐不含该格式，下载会失败。请先到「用量」或「设置」页确认当前套餐，再到「套餐升级」页升级。

另一可能：报告状态还不是「已生成」（生成中 / 排队中 / 失败不可下载），请稍后刷新重试。

Q3分析为什么会失败？失败了怎么办？

常见失败原因：

  • 额度不足：Token 配额用尽，任务在预算校验环节被拦截（显示预算不足类原因）；
  • 数据采集异常：所选平台或关键词未能采到内容；
  • 系统内部错误：极少见，可稍后重试。

失败后详情页会红框显示失败原因，操作区提供「重新运行」按钮——按原参数重新排队执行，会再次消耗 Token。若反复失败：先检查用量页额度是否充足；仍无法解决请联系客服并附上任务 ID（详情页顶部可复制）。

Q4数据从哪来？是真实的吗？

系统面向微博、公众号、新闻、小红书、B 站、抖音 6 个平台的公开内容做采集与分析。当前技术预览阶段使用内置演示数据（真实采集爬虫正在联调），预览环境的结果用于体验流程而非实际舆情；真实采集与真实 AI 研判上线后，分析结果将来自真实的公开讨论内容。见第 7 章。

Q5任务一直停在「排队中」或「数据采集」怎么办？
  • 先确认是否有其他任务正在运行：并发分析数受套餐限制（免费版 1 个 / 专业版 2 个 / 企业版 5 个），超出部分会排队等待空位，属正常现象；
  • 详情页与列表页会自动每 5 秒刷新，也可手动点「刷新状态」；
  • 若长时间（如超过 30 分钟）无任何变化，可取消后「重新运行」；仍有问题请联系客服并提供任务 ID。
Q6取消任务会退次数或 Token 吗？

不会。分析次数按任务创建计次——一经创建即计入当月分析次数，取消不退回；执行中已消耗的 Token 也不退回。「重新运行」不增加分析次数，但会再次消耗 Token。

Q7状态已是「已完成」，为什么结果标签页是空的？

技术预览阶段的分析结果聚合管线尚未完成：文档列表、情感占比、话题聚类可能为空或零值（提示「未采集到公开文档」等），报告下载链路已可用。真实聚合上线后，每次完成的分析都会自动填充结果。见第 7 章。

Q8报告的结论准确吗？能不能溯源？

报告由 AI 基于本次采集的内容自动生成，页面会标注为 AI 生成内容，供参考研判；正式上线后可在「分析详情 → 文档列表」核对原始内容与出处链接，重要处置决策建议结合原文核实。多 Agent 辩论研判（多位专家 AI 分角色辩论后给出结论）将为专业版及以上提供更可靠的研判结果，正在接入中（见第 7 章）。

Q9报告在哪里下载？会保存多久？

两个入口：完成的分析详情页「分析报告」标签页、左侧菜单「报告中心」。报告与原始文档的保存时长取决于套餐的数据保留策略（免费 30 天 / 专业 90 天 / 企业 365 天 / 旗舰永久），到期自动清理，重要报告请及时下载存档。

Q10一个账号能几个人一起用？成员怎么加？

各套餐的团队席位：免费版 1 席、专业版 3 席、企业版 20 席、旗舰版无限制。成员邀请与团队管理即将推出；当前一个团队由注册账号（租户管理员）统一管理。正式版上线后可在「设置」页邀请成员并分配角色（分析师 / 只读成员等）。

Q11忘记密码或想修改注册邮箱怎么办？

密码找回与资料自助修改功能即将推出。当前阶段请联系客服，提供注册邮箱与租户 ID（「设置」页可查）完成重置或修改。

Q12升级套餐后多久生效？怎么支付？

在「套餐升级」页提交订阅请求后系统即受理（提示「订阅请求已提交」）。当前预览阶段为线下开通流程：按「设置」页帮助指引联系客服完成支付与开通，开通后新套餐立即生效，额度、格式等权益随之更新。在线自动支付正在接入，正式上线后支持自助即时开通。

Q13发票怎么开？

账单在正式计费上线后按月出账（「账单」页可查记录），发票文件下载即将推出。当前如需开票，请在支付时向客服说明开票信息（抬头、税号等），由人工开具。

Q14提示「账号已被停用 / 租户已挂起」是什么意思？

说明你的团队空间被平台管理员挂起（常见于欠费或违规处置）。请联系团队负责人或平台客服了解原因与恢复流程；恢复后即可正常登录，数据不会丢失。

Q15「声量」「情感」「话题」这些结果是怎么算出来的？

简要流程：按你设定的关键词与数据源采集内容 → AI 逐条理解并打上情感标签（正面 / 中性 / 负面）→ 将内容按讨论主题聚成话题并观察变化趋势 → 汇总成面板图表与报告。声量指内容条数（讨论热度），情感占比指正面 / 中性 / 负面各占多少，话题聚类把零散讨论归类成主题。面板与详情页的空状态提示均表示当前还没有可用于统计的分析结果。

Q16为什么用一会儿就要重新登录？

为保障安全，登录状态会定时刷新续期；正常使用中页面会自动续期，无需反复输入密码。长时间未操作后提示重新登录，属安全机制的正常表现。
