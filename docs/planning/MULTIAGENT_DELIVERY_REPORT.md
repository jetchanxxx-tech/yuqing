## 🏗️ 技术架构

### 核心设计

```
┌─────────────────────────────────────────────────────┐
│              Go Platform (主系统)                    │
│  ┌──────────────┐                                   │
│  │ Analysis API │──────┐                            │
│  └──────────────┘      │                            │
│                        ▼                             │
│  ┌──────────────────────────────────────────────┐  │
│  │         Forum Engine (Python)                │  │
│  │  ┌──────────┐  ┌──────────┐  ┌───────────┐  │  │
│  │  │Moderator │  │  Agent1  │  │  Agent2   │  │  │
│  │  │ (主持人) │  │事实核查员│  │情绪分析师 │  │  │
│  │  └──────────┘  └──────────┘  └───────────┘  │  │
│  │  ┌──────────┐  ┌──────────┐                  │  │
│  │  │  Agent3  │  │  Agent4  │                  │  │
│  │  │传播专家  │  │处置建议官│                  │  │
│  │  └──────────┘  └──────────┘                  │  │
│  │            ▼                                  │  │
│  │     ┌─────────────┐                          │  │
│  │     │ GLM-4-flash │                          │  │
│  │     └─────────────┘                          │  │
│  └──────────────────────────────────────────────┘  │
│                        │                            │
│                        ▼                            │
│  ┌──────────────────────────────────────────────┐  │
│  │        PostgreSQL Database                   │  │
│  │  debates | debate_metrics | llm_call_logs    │  │
│  └──────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

### 三层差异化设计

1. **人设对立**：「证据先行」vs「情绪更重要」
2. **维度分工**：事实/情绪/传播/策略，显式分工
3. **温度差异**：0.2 - 0.5，确保输出多样性

**验证结果**：观点相似度 < 0.6（目标达成）
