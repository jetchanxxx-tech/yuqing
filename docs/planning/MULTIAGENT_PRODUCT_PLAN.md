## 一、战略背景

### 1.1 产品定位

**核心差异化**：用多 Agent 辩论协作，把"监测"升级为"研判"

**目标用户**：
- 中小企业（50-500 人）市场/公关团队
- 个人品牌（KOL/创始人）
- 新消费品牌创业公司

**痛点解决**：
1. **决策焦虑**：单一 AI 结论缺乏可信度，多角色辩论提供"第二意见"
2. **认知盲区**：专业团队容易陷入思维定式，跨领域专家辩论暴露盲点
3. **解释性需求**：领导层需要理解"为什么"，而非仅看黑盒结论

### 2.4 营销话术（知乎/小红书文案）

#### 知乎回答：《如何评价盘古舆情的"多 Agent 辩论"功能？》

**标题**：亲测盘古舆情 1 个月，说说"5 专家辩论"是不是噱头

**正文**：

> 我是某新消费品牌的市场负责人，之前用过新浪舆情、清博大数据，最近试用了盘古舆情的"多 Agent 辩论"功能，聊聊真实感受。

**先说结论**：不是噱头，但适用场景很明确。

---

**1. 什么是"多 Agent 辩论"？**

简单说，就是 5 个不同领域的 AI 专家（危机公关/品牌战略/消费心理/数据分析/行业专家）会针对同一个舆情事件"开会讨论"，每个专家站在自己的角度给建议，最后由主持人综合各方意见给出结论。

听起来很玄乎，但实际用起来很直观。你能看到完整的"辩论实录"，比如：
- 公关专家说"24 小时内必须回应"
- 品牌专家说"太急了，等 48 小时"
- 然后数据专家拿出数据说"这个案例和奶茶品牌不一样"

**这就是我说的"不是噱头"** —— 真的有不同观点在交锋，不是 5 个 AI 复读同一句话。

---

**2. 什么时候有用？什么时候没用？**

**✅ 有用的场景**：
- **领导要你"多维度分析"**：直接把辩论过程截图放 PPT，5 个专家视角老板一看就懂
- **自己拿不准主意**：比如我上次遇到"产品差评"，不知道该立即下架还是继续卖。5 专家里有 3 个说"先内部排查质量问题"，2 个说"立即下架"，我心里就有谱了
- **需要向上级解释"为什么这么决策"**：传统 AI 只给结论，老板问"凭什么"你答不上来；多 Agent 辩论有完整推理链，能说清楚

**❌ 没用的场景**：
- **纯监测需求**：如果你只需要"告诉我有多少负面"，不需要辩论，传统工具更快
- **紧急危机**：真的火烧眉毛了，没时间看 5 个专家吵架，直接找真人公关顾问
- **预算紧张**：多 Agent 辩论消耗 token 多（15 次 LLM 调用），成本比单 AI 高

---

**3. 和真人专家比，差距在哪？**

坦白说，**还是有差距的**。

真人公关顾问能结合你的公司内部情况（比如"上个月刚发过类似声明，这次再发会显得重复"），AI 专家做不到这么精细。

但优势是：
- **便宜**：真人顾问看一次舆情 3000-5000 元，盘古舆情 Pro 版 999/月包 10 次
- **快**：3 小时出结果 vs 真人 2 天
- **7×24 小时**：半夜突发舆情也能立即分析

我的用法是：**日常监测用盘古舆情，真的遇到大危机再请真人顾问**。

---

**4. 总结**

如果你是：
- 中小企业（没预算养专职公关团队）
- 需要向领导汇报"多角度分析"
- 想理解 AI 的推理过程（而非只要黑盒结论）

那盘古舆情的多 Agent 辩论值得试试。

如果你是：
- 大厂（有专业团队）
- 只需要数据监测
- 预算敏感（每次分析成本在意几块钱）

那传统工具可能更合适。

---

我的评分：**功能 8/10，性价比 9/10**（Pro 版 999/月很划算）

唯一槽点：辩论过程有时候有点啰嗦，希望后续能出个"精简模式"。

**状态管理**：
```typescript
interface DebateViewerState {
  level: 1 | 2 | 3;  // 当前展开层级
  isExpanding: boolean;  // 动画状态
  debateData: {
    conclusion: string;
    riskLevel: 'low' | 'medium' | 'high';
    responseTime: string;
    actions: string[];
    experts: Array<{
      role: string;
      name: string;
      emoji: string;
      summary: string;
    }>;
    rounds: Array<{
      roundNum: number;
      messages: Array<{
        timestamp: string;
        speaker: string;
        content: string;
        type: 'statement' | 'challenge' | 'consensus';
      }>;
    }>;
  };
}
```

**Props**：
```typescript
interface DebateViewerProps {
  analysisId: string;
  onLevelChange?: (level: number) => void;  // 埋点用
}
```

**交互逻辑**：
1. 默认展示 Level 1（结论）
2. 点击"查看辩论依据"→ 300ms 展开动画 → Level 2（专家摘要）
3. 点击"完整辩论回放"→ 300ms 展开动画 → Level 3（时间线）
4. Level 3 状态下点击"关闭"→ 收起回 Level 2
5. Level 2 状态下再次点击"收起"→ 回到 Level 1

**埋点事件**：
```typescript
track('debate_level_changed', {
  analysis_id: string,
  from_level: number,
  to_level: number,
  time_spent_seconds: number,  // 在上一层级停留时长
});
```

### 5.2 长期方案（v0.2.0+）

| 套餐 | 价格 | 辩论模式 | 差异点 |
|------|------|---------|--------|
| **Free** | 0 | ❌ 无辩论 | 只有基础情感分析 + 话题聚类 |
| **Lite** | 99/月 | ⚠️ 3 专家 × 1 轮 | 快速版（公关/品牌/心理 3 专家，无交锋环节） |
| **Pro** | 999/月 | ✅ 5 专家 × 3 轮 | 完整辩论（含数据专家 + 行业专家） |
| **Enterprise** | 4999/月 | ✅ + 自定义专家 | 可根据行业定制专家人设（如"医疗法规专家"） |

**定价逻辑**：
1. Free → Lite：体验"多专家"价值（3 专家 vs 单 AI 已有显著差异）
2. Lite → Pro：完整辩论 + 行业专家（"数据专家"和"行业专家"是 Pro 独占）
3. Pro → Enterprise：定制化（大客户可提交"专家需求单"，如金融行业需要"合规专家"）

## 六、数据埋点与 A/B 测试计划

### 6.1 关键指标

**北极星指标**：**辩论功能使用率**（有多少用户点开 Level 2/3）

**辅助指标**：
1. **Level 渗透率**：
   - Level 1 → Level 2 转化率（目标 > 30%）
   - Level 2 → Level 3 转化率（目标 > 10%）
2. **停留时长**：
   - Level 2 平均停留（目标 > 30 秒）
   - Level 3 平均停留（目标 > 2 分钟）
3. **业务影响**：
   - 看过辩论 vs 未看辩论的用户，续费率差异
   - 看过辩论 vs 未看辩论的用户，NPS 差异

---

### 6.2 A/B 测试方案

**测试假设**：辩论功能能提升用户对 AI 结论的信任度，从而提高续费率

**测试设计**：
- **对照组 A**（50% 流量）：隐藏辩论功能，只展示最终结论（Level 1）
- **实验组 B**（50% 流量）：完整 3 层辩论展示

**测试周期**：4 周

**成功标准**：
1. 实验组 B 的 7 日留存率 > 对照组 A **至少 5%**
2. 实验组 B 的月度续费率 > 对照组 A **至少 10%**
3. 实验组 B 的 NPS 得分 > 对照组 A **至少 8 分**

**失败后备方案**：
如果实验组数据**更差**（说明辩论功能反而干扰用户），则：
1. 将辩论功能改为"Pro/Enterprise 专属"（不对 Free/Lite 开放）
2. 或改为"可选功能"（用户需在设置中主动开启）
