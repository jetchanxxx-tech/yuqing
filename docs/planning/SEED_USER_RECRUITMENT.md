## 三、激励发放流程

### 3.1 激励层级设计

| 层级 | 条件 | 奖励 | 发放时间 | 预算 |
|------|------|------|---------|------|
| **L1** | 完成问卷注册 | Pro免费1个月（10次额度） | 24h内 | ¥0（系统自动） |
| **L2** | 提交1条有效反馈 | ¥50红包 | 7日内 | ¥5000（100人×¥50） |
| **L3** | 完成3次任务+30分钟访谈 | ¥200京东卡 | 14日内 | ¥4000（20人×¥200） |
| **L4** | 邀请1位同行注册 | 双方各得10次额度 | 即时 | ¥0（系统自动） |

**总预算**：¥9000（超出¥3000预算，需申请追加或调整L2/L3标准）

### 3.2 "有效反馈"定义

符合以下任一条件：
1. **功能建议**：具体可落地（如"希望支持抖音数据源"）
2. **Bug报告**：可复现的问题 + 截图
3. **使用场景**：真实业务场景描述（≥200字）
4. **竞品对比**：与清博/识微对比体验（≥3个维度）

**不符合标准**：
- ❌ "挺好的"（无实质内容）
- ❌ "界面可以更好看"（过于笼统）
- ❌ 恶意刷单（同一人多账号）

### 3.3 发放操作流程

**L1（Pro账号开通）**：
1. 用户填写问卷 → 系统webhook触发
2. 运营审核（5分钟）：检查信息真实性
3. 后台操作：
   ```bash
   # 管理员后台"用户管理"页面
   # 找到用户 → "调整套餐" → 选择"Pro试用版"
   # 有效期：30天，额度：10次
   ```
4. 自动发送欢迎邮件（含使用指南）

**L2（¥50红包）**：
1. 用户提交反馈 → 运营记录在《反馈汇总表》
2. 24h内审核是否符合"有效反馈"标准
3. 通过：微信/支付宝转账¥50
4. 更新《激励发放记录表》

**L3（¥200京东卡）**：
1. 用户完成3次任务 → 系统埋点统计
2. 运营主动联系预约访谈（腾讯会议30分钟）
3. 访谈结束24h内，京东卡密码发送至邮箱
4. 更新《深度用户档案》

**L4（推荐奖励）**：
1. 用户A分享专属邀请码 → 用户B注册
2. 系统自动检测关联关系
3. 双方账户各增加10次额度
4. 站内信通知"您的邀请奖励已到账"

### 3.4 防刷机制

**风险点**：
- 同一人注册多个账号刷奖励
- 虚假反馈刷¥50红包
- 串通刷邀请奖励

**防范措施**：
1. **身份验证**：邮箱+手机号双重验证（已有用户中心支持）
2. **IP检测**：同一IP 24h内注册≥3个账号 → 人工审核
3. **反馈质量**：运营人工审核，笼统内容不通过
4. **邀请限制**：单个用户最多邀请10人（超出需申请）

### 3.5 数据追踪

**运营看板**（每日更新）：
| 指标 | 目标 | 实际 | 完成率 |
|------|------|------|--------|
| 注册人数 | 100 | - | - |
| 激活率（完成首次任务） | 70% | - | - |
| 有效反馈数 | 50条 | - | - |
| 深度访谈数 | 20人 | - | - |
| 邀请裂变率 | 30% | - | - |

**数据来源**：
- 注册数：用户中心后台
- 激活率：埋点统计（创建任务→查看报告）
- 反馈数：《反馈汇总表》（腾讯文档）
